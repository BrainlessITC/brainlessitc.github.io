Developers

Template overrides, hooks and functions.

Template overrides

Copy a template from the plugin's templates/ folder to your theme, keeping the path:

yourtheme/brainlessitc-pdf-invoices-packing-slips-for-woo/invoice/classic.php
yourtheme/brainlessitc-pdf-invoices-packing-slips-for-woo/invoice/modern.php
yourtheme/brainlessitc-pdf-invoices-packing-slips-for-woo/packing-slip/default.php

Templates receive a prepared $data array. Text values are plain text (escape with esc_html()); keys ending in _html contain WooCommerce price/address HTML (print with wp_kses_post()).

Filters

  • bitcpdf_document_types — register document types (extend BrainlessITC\PdfInvoices\Documents\Document).
  • bitcpdf_invoice_templates — add invoice layouts.
  • bitcpdf_template_data, bitcpdf_document_item, bitcpdf_document_totals, bitcpdf_document_css — change what is printed.
  • bitcpdf_number_series, bitcpdf_formatted_number, bitcpdf_can_issue_invoice — numbering.
  • bitcpdf_document_filename, bitcpdf_email_options, bitcpdf_skip_email_attachments, bitcpdf_admin_capability, bitcpdf_bulk_limit, bitcpdf_dompdf_options.
  • bitcpdf_settings_tabs, bitcpdf_settings_fields — add settings for add-ons.

Actions

  • bitcpdf_loaded, bitcpdf_document_issued, bitcpdf_pdf_generated.
  • bitcpdf_order_meta_box_after, bitcpdf_settings_after_form.
  • bitcpdf_template_before_items, bitcpdf_template_item_after_meta, bitcpdf_template_after_totals — template hooks (escape your output).

Functions

bitcpdf_get_invoice_number( $order );            // '' when no invoice was issued
bitcpdf_get_admin_document_url( 'invoice', array( $order_id ) );

Data

Issued numbers are stored in {prefix}bitcpdf_documents (unique keys on series + number and on document type + order + reference) and counters in {prefix}bitcpdf_sequences. A copy of the invoice number is stored on the order as _bitcpdf_invoice_number. Settings are in the option bitcpdf_settings.
