Developers

Templates, hooks and helper functions to customize Giftora.

Templates

Copy a template from the plugin's templates/ folder to yourtheme/giftora-gift-cards-for-woocommerce/ and edit it there.

TemplateUsed for
single-product/add-to-cart/giftora-gift-card.phpPurchase form on the product page
cart/giftora-redeem-form.php"Have a gift card?" form (classic cart / checkout)
balance-form.phpBalance checker
emails/giftora-gift-card.php, emails/plain/giftora-gift-card.phpGift card email
pro/…Pro templates: design picker, PDF, My Account, Pro emails

Actions

  • giftora_loaded( $plugin ) — after the plugin is loaded.
  • giftora_card_created( $card, $args ), giftora_card_issued( $card, $order ), giftora_order_cards_issued( $cards, $order )
  • giftora_card_delivered( $card, $resend ), giftora_card_applied( $card ), giftora_card_status_changed( $id, $status, $old )
  • giftora_order_reconciled( $order, $released ) — after card balances of an order were updated.
  • giftora_purchase_form_fields( $product ), giftora_validate_purchase( $errors, $data, $product, $qty )

Filters

  • giftora_generated_code, giftora_code_groups — code format.
  • giftora_create_card_args, giftora_issue_card_args — data of new cards.
  • giftora_product_amounts, giftora_product_custom_amount_range, giftora_purchase_data, giftora_purchase_description
  • giftora_validate_card_for_cart, giftora_can_apply_card, giftora_cart_eligible_total, giftora_max_cards_per_order
  • giftora_deliver_card_now, giftora_card_image_url, giftora_gift_card_email_attachments
  • giftora_rate_limit_attempts, giftora_rate_limit_window

Functions

  • giftora_get_card( $id_or_code ) — returns a card object or null.
  • giftora()->cards->create( array( 'amount' => 50, 'recipient_email' => '…' ) ) — create a card.
  • giftora()->cards->debit( $id, $amount ) / credit() / set_balance() — atomic balance changes, logged in the history.
  • giftora()->emails->deliver( $card ) — send the gift card email.

Data

Gift cards are stored in {prefix}giftora_cards, their history in {prefix}giftora_transactions. Settings are WooCommerce options named giftora_*. Orders keep the cards they used in the order meta _giftora_redemptions (and what was actually taken in _giftora_debits).
