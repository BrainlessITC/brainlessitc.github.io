Shortcodes

ShortcodeOutput
[blraq_quote]The quote list and request form — same as the Request a Quote block. Place it on the page selected as Quote page.
[blraq_quote_link label="Quote" show_count="yes"]A link to the quote page. label sets the text (default "Quote"); show_count adds the number of products in the list (yes / no).
[blraq_button id="123"]An "Add to quote" button for product 123. Without id it uses the current product.

Examples

Add these snippets to a small custom plugin or with a code-snippets plugin.

Let shop managers without full WooCommerce rights manage quotes

add_filter( 'blraq_manage_capability', function () {
    return 'edit_shop_orders'; // Default: manage_woocommerce.
} );

No quotes for one category

add_filter( 'blraq_is_product_quotable', function ( $quotable, $product ) {
    $id = $product->get_parent_id() ? $product->get_parent_id() : $product->get_id();
    if ( has_term( 'gift-cards', 'product_cat', $id ) ) {
        return false;
    }
    return $quotable;
}, 10, 2 );

Add a "VAT number" field to the form

add_filter( 'blraq_form_fields', function ( $fields ) {
    $fields['vat_number'] = array(
        'type'     => 'text',
        'label'    => __( 'VAT number', 'my-textdomain' ),
        'required' => false,
        'class'    => array( 'form-row-wide' ),
        'priority' => 55, // Company is 50, Message 60.
    );
    return $fields;
} );

The value is sanitized, validated and stored with the quote like the built-in fields, and shown on the quote screen and in emails.

Send new requests to your CRM

add_action( 'blraq_quote_created', function ( $quote_id, $quote ) {
    wp_remote_post( 'https://crm.example.com/api/leads', array(
        'body' => array(
            'name'  => $quote->get_customer_name(),
            'email' => $quote->get_customer_email(),
            'quote' => $quote->get_number(),
        ),
    ) );
}, 10, 2 );

Prefix quote numbers

add_filter( 'blraq_quote_number', function ( $number, $quote ) {
    return 'Q-' . str_pad( $number, 5, '0', STR_PAD_LEFT ); // Q-00058
}, 10, 2 );

React to status changes

add_action( 'blraq_quote_status_changed', function ( $quote, $old_status, $new_status ) {
    if ( 'accepted' === $new_status ) {
        // e.g. notify your sales team.
    }
}, 10, 3 );
// Or listen to one status only: blraq_quote_status_{status}, e.g. blraq_quote_status_accepted ( $quote, $old_status ).

Webhooks PRO

Configure delivery URLs and a signing secret in Settings › Integrations. Events are delivered in the background as an HTTP POST with a JSON body.

EventWhen
quote.createdA new quote request was submitted.
quote.status_changedA quote changed status.

Headers

  • Content-Type: application/json
  • X-BLRAQ-Event — the event name.
  • X-BLRAQ-Delivery — a unique ID per delivery.
  • X-BLRAQ-Signature — when a secret is set: base64 of the HMAC-SHA256 of the raw body, keyed with your secret.

Payload

{
  "event": "quote.created",
  "site": "https://example.com/",
  "quote": {
    "id": 58,
    "number": "58",
    "status": "new",
    "status_label": "New",
    "currency": "USD",
    "total": 1080,
    "customer": { "id": 0, "name": "Sofia Martinez", "email": "sofia@example.com" },
    "fields": {
      "company": { "label": "Company", "value": "Casa Boutique" },
      "message": { "label": "Message", "value": "Wholesale pricing for 3 products." }
    },
    "items": [
      {
        "product_id": 21, "variation_id": 0, "name": "Shoes", "sku": "woo-fashion-shoes",
        "quantity": 30, "price": 18, "offered_price": null, "attributes": {}
      }
    ],
    "order_id": 0,
    "created_at": "2026-10-01T06:02:00+00:00",
    "expires_at": null,
    "admin_url": "https://example.com/wp-admin/admin.php?page=blraq-quotes&quote=58"
  },
  "sent_at": "2026-10-01T06:02:05+00:00"
}

Verify the signature (PHP)

$body      = file_get_contents( 'php://input' );
$expected  = base64_encode( hash_hmac( 'sha256', $body, 'your-signing-secret', true ) );
$signature = isset( $_SERVER['HTTP_X_BLRAQ_SIGNATURE'] ) ? $_SERVER['HTTP_X_BLRAQ_SIGNATURE'] : '';

if ( ! hash_equals( $expected, $signature ) ) {
    http_response_code( 401 );
    exit;
}
$event = json_decode( $body, true );

Stored data

  • Custom tables: {prefix}blraq_quotes, {prefix}blraq_quote_items, {prefix}blraq_quote_notes and {prefix}blraq_quotemeta. Compatible with WooCommerce HPOS.
  • Options: blraq_settings; with Pro also blraq_pro_settings, blraq_pro_rules and blraq_pro_form.
  • Product meta: _blraq_quote, _blraq_hide_price, _blraq_hide_atc (per-product overrides).
  • Pro uploads: files from upload fields are stored in a protected folder inside wp-content/uploads and served only to store managers.
  • Nothing is removed on deactivation; see Remove data on uninstall.
